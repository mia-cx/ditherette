Free-play memory probe

Peak model includes input RGBA8, optional resized RGBA8, the selected working buffer, and indexed output. Full-image diffusion adds another f32 × 3 buffer. The line is the threaded build’s current 2 GiB ceiling; scalar consumers can be tighter.

Guided boundary checks

Precision challenge

Comparing f32 and f16 nearest-color decisions over 65,536 deterministic RGB samples against Wplace’s 63 visible colors…

f16 is included to falsify the f32 choice. It saves another 50%, but WebAssembly has no native f16 arithmetic in the required scalar baseline, so every store/load needs conversion and palette-boundary changes are observable. f64 doubles memory with no input precision to recover.

Contract consequences

Inside one method

Resize, colorspace conversion, dither, and quantize stay inside Wasm. No working-color buffer crosses JS.

Stage methods

resize() and separable dither() return copied RGBA8. Quantizing methods return copied indices plus palette metadata.

Later optimization

SoA, SIMD, lookup tables, and cache budgets remain replaceable internals. Revisit only with an end-to-end consumer benchmark.
