# #383 Improve SEO for Wplace templates, colour conversion and dithering

## Summary

Make https://ditherette.mia.cx discoverable for Wplace template preparation, Wplace colour
conversion, dithering and palette quantisation. Add a few server-rendered guides that lead
into the editor, plus accurate titles, descriptions, canonicals, social previews, a sitemap
and robots rules. The editor stays at `/` and keeps its focused workflow.

## Acceptance criteria

- [ ] A recorded audit identifies the current gaps and the implemented remedies.
- [ ] Public pages answer the Wplace and image-conversion intents without keyword stuffing or doorway pages.
- [ ] Titles, descriptions, canonicals, social previews, sitemap and robots use the production domain and pass focused checks.
- [ ] Search engines can read useful content and follow links without running the editor.
- [ ] Claims match shipped capabilities; template preparation is distinguished from placing pixels.
- [ ] Mobile usability, accessibility and editor behaviour remain sound; labelled before/after evidence.
- [ ] Post-deployment indexing checks documented; Search Console verification recorded as Mia's follow-up.

## Baseline audit (production, 2026-10-15, main at 3e05dac9)

- `/` returns 200 with only `<title>ditherette</title>`. No description, canonical, Open Graph,
  Twitter card or structured data. No `<h1>`. The SSR body holds the menu bar and export bar only.
- The favicon is the Svelte template logo (`src/lib/assets/favicon.svg`), not a Ditherette mark.
- `/robots.txt` exists and allows everything. It names no sitemap. (The issue assumed no robots file.)
- `/sitemap.xml` and `/guides` return 404. No public content pages exist.
- `/?foo=bar` returns the same page with no canonical, so parameter variants are unconsolidated.
- `http://` redirects 301 to `https://`. `www.` does not resolve. The workers.dev host returns 404.
- `/api/events` answers 405 to GET.

## Platform facts checked (primary sources)

- Wplace bundle (wplace.live, fetched 2026-10-15): 64 entries, index 0 Transparent; `hasColor(e)`
  grants `e < 32`, the rest need unlocking. So: Transparent, 31 free, 32 unlockable.
  Ditherette's built-in palette matches this split and 62 of 63 hex values. Its Teal is
  `#10AE82`; Wplace serves `#10AEA6`. Filed separately; the guides avoid claiming exact parity.
- Wplace's overlay guide: upload PNG, WebP, JPG, ORA or PSD; the anchor is the top-left pixel;
  check converted colours before saving; a reference does not place pixels.
- Google: `SoftwareApplication` rich results need a rating or review, which Ditherette lacks, so
  it is not used. `WebSite` on the home page states the site name. Google ignores sitemap
  `priority`/`changefreq` and uses `lastmod` only when accurate, so neither is emitted.
- Keyword phrases from the issue are hypotheses, not volume data. Copy uses the words the
  product and Wplace use: template, overlay, colours/colors, palette, dithering, quantisation.

## Design

- Routes: `/guides` hub, `/guides/wplace-template`, `/guides/wplace-colours`,
  `/guides/dithering`, `/guides/colour-quantisation`. Prerendered with `csr = false`: plain
  HTML and CSS, no editor JavaScript, workers or Wasm.
- `$lib/guides.ts` is the registry for titles, descriptions, the hub list, cross-links and the sitemap.
- `$lib/seo.ts` holds the production origin, canonical URLs and the sitemap XML.
- `Seo.svelte` writes title, description, canonical, Open Graph and Twitter tags, and JSON-LD.
- Editor `/`: descriptive title and description, canonical, `WebSite` JSON-LD, and a Guides link in the app bar.
- `robots.txt` names the sitemap and keeps crawlers off `/api/`.
- Examples are real Ditherette exports of a procedural source image.
